## Kullanım kuralı

ChatGPT yeni bir CSE sohbetinde önce GitHub repository gerçeğini kontrol eder; bu tarihli dosyaları yalnız bağlam ve yönlendirme katmanı olarak kullanır.

```text
GitHub master / PR / Issue / branch kanıtı
→ current GitHub Issue
→ docs/protocols/CSE_UNIFIED_PROJECT_SOURCE.md
→ docs/protocols/CSE_PROJECT_INSTRUCTIONS.md
→ .cse state/result
→ README / ROADMAP / CHANGELOG
→ docs/chatgpt_sources tarihli bağlam dosyaları
→ tarihsel PDF, ZIP ve eski yüklemeler
```

Tarih ya da commit bilgisi güncelliğini kaybettiğinde GitHub’ın current Issue/PR/master gerçeği üstündür. Bu dosyalar repository gerçeğini override etmez.
