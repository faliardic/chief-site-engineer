Değişken proje durumu için GitHub gerçeği üstündür:

```text
GitHub master / PR / Issue / branch kanıtı
→ current GitHub Issue
→ tracked kanonik proje kaynağı
→ tracked operasyon talimatı
→ .cse state/result
→ README / ROADMAP / CHANGELOG
→ tarihsel PDF, ZIP ve eski yüklemeler
```

PR `#142` henüz merge edilmemişti. Bu nedenle `ac2942b...` yeni merged safe point olarak
sunulmaz. Merge sonrasında yalnız güncel durum dosyasının ve güvenli nokta satırlarının yenilenmesi
gerekir.
