# CSE Result Template

FAST iş bu şablonu kullanmaz.

## STANDARD — yalnız gerekiyorsa

```text
Issue/task:
Status: completed | partial | blocked
Base/head:
Changed behavior:
Changed paths:
Codex static checks:
Fatih validation:
Branch/PR:
Remaining risk:
Next action:
```

Hedef uzunluk 10–15 satırdır.

## CRITICAL extension

Gerektiği kadar eklenir:

```text
Critical trigger:
Schema/backup/version before/after:
Migration/rollback:
Identity/revision/transaction/history:
Attachment/user-file integrity:
Security/permission/platform:
Compatibility evidence:
Focused/integration/device/release results:
Real-user data mutation:
Artifact provenance:
Owner Ready/merge/release decision:
```

Kanıtlanmayan `PASS`, push, temiz worktree veya divergence sonucu yazılmaz.
