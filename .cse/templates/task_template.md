# CSE Task Template

FAST iş bu şablonu kullanmaz.

## STANDARD — yalnız gerekiyorsa

```text
Issue/task:
Goal / changed behavior:
Expected base:
Working branch:
Allowed paths:
Protected contracts:
5-minute micro step:
Fatih validation:
Stop conditions:
Publication boundary:
```

Hedef uzunluk 10–20 satırdır.

## CRITICAL extension

STANDARD alanlarına gerektiği kadar eklenir:

```text
Critical trigger:
Schema/migration:
Backup/restore:
Identity/revision/transaction/history:
Attachment/user-file integrity:
Security/permission/signing/platform:
Real-user data/destructive boundary:
Compatibility/rollback:
Focused/integration/device/release gates:
Provenance requirements:
Ready/merge/release authority:
```

Değişmeyen contract için uzun tekrar yazılmaz; `not impacted` yeterlidir.
